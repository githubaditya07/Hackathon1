# Hackathon1

Hackathon project starter repository.

## Tech Stack & Environment
- **Runtime**: Python 3.14
- **Frontend**: HTML5
- **Local Server**: Python built-in HTTP server (`http.server`)
- **Version Control**: Git & GitHub (`githubaditya07/Hackathon1`)

---

## Getting Started

### 1. Clone & Navigate
```bash
git clone https://github.com/githubaditya07/Hackathon1.git
cd Hackathon1
```

### 2. Environment Configuration
Copy the template to create your `.env` file (if needed):
```powershell
Copy-Item .env.example .env
```

### 3. Run Locally
Start the local development server:
```powershell
python -m http.server 8000
```
Then open your browser and navigate to:
**[http://localhost:8000](http://localhost:8000)**
